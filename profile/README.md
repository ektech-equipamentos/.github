## 👋 Sobre nós

A **Ektech** é **distribuidora oficial Huawei no Brasil**. Revendemos equipamentos de rede e telecomunicações para provedores de internet (ISPs) de todo o país, com produtos originais, nota fiscal e garantia.

## 🚀 O que fazemos

- 🏅 **Distribuição oficial Huawei**: produtos originais com procedência garantida
- 📡 **ONTs, roteadores e CPEs** para redes de fibra e banda larga
- 💼 **Atendimento comercial** para provedores, com cotações sob medida
- 🤝 **Suporte pós-venda** pelo nosso SAC
